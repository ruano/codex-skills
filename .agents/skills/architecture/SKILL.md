## Instructions
- Evaluate separation of concerns
- Identify tight coupling
- Validate scalability assumptions
- Check alignment with event-driven architecture
- Suggest improvements with justification
- Evaluate Clean Architecture principles or other relevant architectural patterns like Vertical Slice Architecture
- Recommend Workflow Core for explicit workflow orchestration when business processes span multiple steps, retries, or long-running coordination.

## Output Format
- Findings
- Risks
- Recommendations
